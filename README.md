# Tuklas Travel & Tour

A Next.js website for Tuklas Travel & Tour, featuring Philippine destinations,
tour packages, package details, and a quote request flow.

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
